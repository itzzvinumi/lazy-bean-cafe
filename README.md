
# Lazy Bean Café Website

A responsive, single-page website for **Lazy Bean Café**, built as a course assessment project for the *Web Design for Beginners* program offered by the Centre for Open & Distance Learning (CODL), University of Moratuwa.

---

## ☕ Features

* **Interactive Coffee Price Calculator:** Built with vanilla JavaScript to calculate order totals dynamically in Sri Lankan Rupees (LKR).
* **Responsive Layout:** Designed to look great across desktop and mobile browsers using HTML5 & CSS3.
* **Structured Information:** Includes an opening hours table, menu highlights, image gallery, and navigation hyperlinks.

---

## 🛠️️ Built With

* **HTML5** – Page structure and semantic content
* **CSS3** – Custom styling, typography, and responsive layout
* **JavaScript (ES6)** – Dynamic price calculation functionality
